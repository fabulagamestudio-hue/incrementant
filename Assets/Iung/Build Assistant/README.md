# Build Assistant

Build Assistant is a Unity editor tool for managing build versions, validation checks and release workflow automation.

## Features

- Build version management
- Build validation workflow
- Build history support
- Release workflow assistance
- Optional TextMeshPro version label component

## Requirements

- Unity 2021.3 or newer
- TextMeshPro package

TextMeshPro is declared as a package dependency in `package.json`.

## Installation

Import the package through the Unity Package Manager or install it as a local UPM package.

## Usage

Open the Build Assistant window from the Unity menu:

```text
Iung > Build Assistant > Open
```

Use the tool to configure build settings, validate release conditions and manage version-related workflow tasks before creating a build.

## Runtime Component

The runtime assembly includes an optional TextMeshPro-based version label component that can be used to display the current build version in UI.
